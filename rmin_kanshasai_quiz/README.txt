R民感謝祭 クイズシステム（インターネット公開向けスターター）

必要なもの
- Node.js 20 以上
- ホスティングサービス（Node.js / WebSocket対応。例：Render、Railway等）
- 公開先の環境変数 HOST_PIN（司会者用PIN。必ず独自の値に変更）

ローカル起動
1. このフォルダで `npm install`
2. `HOST_PIN=自分だけが知る長いPIN npm start`（Windows PowerShellでは `$env:HOST_PIN="自分だけが知る長いPIN"; npm start`）
3. ブラウザで http://localhost:3000 を開く
4. 司会者タブでPINを入力。表示された参加コードを参加者へ共有。
   ※localhost は自分のPCだけ。インターネット公開にはホスティング設定が必要です。

公開する際
1. このフォルダをGitHubリポジトリにアップロード
2. Node Web Serviceとしてデプロイし、Build command `npm install`、Start command `npm start`
3. Environment Variables に `HOST_PIN` を設定
4. 公開URLを開いて動作確認

機能
- スマホ参加、最大10人
- 4択回答、早押しボタン、制限時間、正解発表、得点とランキング
- 送ってもらった背景、R民感謝祭ロゴ、選択肢番号、正解・不正解・お待ちください画像、Gisshiri.ttfを使用
- サンプル問題入力

重要な注意
- これは公開に向けたスターターで、ホスティングへの実デプロイや公開URL発行はまだ行っていません。
- 現在の状態はサーバーのメモリ内だけに保存されます。サーバー再起動で部屋・得点が消えます。
- 参加コードは起動時に生成され、1プロセスで1部屋です。複数部屋・永続保存・本格的な認証が必要なら追加実装してください。
- 本番イベントで使う前に、実際のスマホ複数台で接続テストしてください。
